## 2. 用户定下的工作规则（必须继续遵守）

1. 先读现有代码和测试，再决定修改方案；修改前说明现状、根因假设、验证方式。
2. 保持公开 API 尽可能兼容；不重写无关模块。
3. 不引入 LangGraph / AG2 或完整多智能体平台。
4. **每次只做一个小切片，改完立即跑对应测试**，绿了才提交。
5. 测试不得访问真实 LLM/网络：一律 `ScriptedModel` + `httpx.MockTransport` + 临时目录 SQLite。
6. **字符串黑名单不是安全隔离**；高风险工具保持禁用占位，真隔离属 sandbox 任务。

- **P2-C RunState 持久化 + 审批恢复**（依赖 B）：新表 `runs`（run_id、三键、status、step、usage、error/error_kind、pending_approval JSON）；`RunStatus.PAUSED` 生效：`ToolPolicy` 判定"需审批"的工具调用时运行暂停（状态+消息落库，含待回填的 tool_call）；`AgentRuntime.run(state, user_input=None)` 的恢复路径已预留（基于已有 messages 继续）；审批通过后**同 run_id** 恢复执行；拒绝则按 tool_error 回填。验收：暂停→进程重启→批准→继续→完成，全程一个 run_id。
- **P2-D ToolPolicy + 审计**：策略独立于工具（allow/needs_approval/timeout/output_limit/network）；结构化错误分类已就位（error_kind）；审计 = EventStore 的 TOOL_CALLED/TOOL_RETURNED + 脱敏选项。验收：无权限/未审批的工具一次都不执行（用 ScriptedModel + 计数工具断言 calls==0）。

- **P2-G 长历史与记忆治理**：窗口截断 + 摘要压缩（摘要调用走同一 ModelClient，测试用 ScriptedModel）；MemoryService namespace/TTL/删除/来源，不无条件全量入向量库。

## 4. 必须保持的核心契约（改动前自查）

1. **三键隔离**：一切存储访问带全 `tenant_id/user_id/session_id`；不存在只按 session_id 查询的路径；空键抛 `ValueError`（注意 `list_sessions` 只有两键，`_ensure_keys(*keys)` 按实际传入校验）。
2. **Runtime 无状态**：RunState 显式传入传出；网关只经 `ConversationService`，不得绕过。
3. **增量持久化**：`RunState.persisted_messages` 是 save 游标，`save()` 只追加增量，幂等；重启恢复不重复写入。
4. **失败语义**：模型异常/超限/取消 → FAILED + `error_kind`；工具异常（含未知工具/参数坏/超时/被过滤）不终止运行，以 `tool_error:` 消息回填；失败运行已产生的消息仍持久化。
5. **单一组装入口**：CLI/Web/Skill/后续 Job 都从 `build_runtime(config, *, model, store, skill_dir, on_event)` 拿 `RuntimeBundle`；`model/store` 注入点专供测试。
6. **技能单一路径**：`SkillAsTool` 经注册时捕获的同一 runtime 实例执行；子运行 `tool_names` 排除 `skill_*`。

## 5. 测试编写约定与已知坑

- `tests/conftest.py` 提供 `db_path` fixture；`asyncio_mode = "auto"`（async 测试函数无需装饰器）。
- **ScriptedModel 是共享队列**：父子运行（技能）共用一个模型实例时，脚本按实际消费顺序排列——父请求工具调用 → 子终答 → 父终答。忘记排顺序会出现 "no scripted response left"（历史上踩过，见 `test_skill_via_full_stack_parent_chat` 注释）。
- 断言"模型看到了什么"用 `model.requests`（每条是 Message 列表）；并发隔离断言用它做"请求纯净性"检查（见 `test_acceptance_phase1.py` AC1）。
- 截止时间/耗时测试用注入 clock（`make_clock`），不要真实 sleep；超时类工具测试 0.01~0.05s 以内。
- 导入写正常 `from x import y`；本会话曾四次写出 `__import__(...)` 反模式，均已在当次修正——**不要再犯**。
- `AgentRuntime` 的 `clock` 参数显式传 `None` 是合法的（回落 monotonic）。
- 新增 dataclass 字段一律放最后并带默认值（保持位置兼容）。
